# Introducción a la Inteligencia Artificial

Repositorio académico que compila las prácticas y proyectos desarrollados durante el curso de **Introducción a la Inteligencia Artificial** en la *Maestría en Inteligencia Artificial*.

---

### 📋 Contenido del Curso

El repositorio organiza de forma secuencial las prácticas de laboratorio y ejercicios del curso:

* **Conceptos básicos de inteligencia artificial** 
* **Agentes** 
* **Búsqueda no Informada** 
* **Búsqueda informada**
* **Perceptrón Multicapa** 
* **Visión computacional**
